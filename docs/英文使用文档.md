## 📖 Core Philosophy

**ResearchMind** is not just a tool; it is a **Multi-Agent Co-Evolution Algorithm**. It seamlessly fuses the logical reasoning of **Large Language Models (LLMs)** with the precision of **Scientific Computing (MatterSim/AI4Kappa)**, creating a **"Generation-Validation-Decision"** closed-loop ecosystem for materials scientists.

---

## 🧠 Intelligence Matrix

ResearchMind consists of four deeply specialized agents that function like experts in a research team, collaborating via a high-speed bus.

### 1. 📖 Literature Research Agent (The Deep Analyst)
> *“Piercing through the fog of information to exact knowledge crystals.”*

*   **⚡ Core Capabilities**:
    *   **Omni-Search**: Scans multi-dimensional sources like ArXiv, Semantic Scholar, and Tavily in parallel.
    *   **Cost-Aware Logic**: Intelligently distinguishes between "Fast Search" and "Deep Report" intents, automatically balancing response speed and Token consumption.
    *   **Semantic Vector Enhancement**: Built-in vector database supports high-dimensional **Semantic Vector Search** on local literature repositories.
*   **🛠️ Tech Under the Hood**:
    *   Utilizes a **RAG (Retrieval-Augmented Generation)** architecture combined with **Chain-of-Thought** reasoning to construct structured knowledge graphs from scattered literature.

### 2. 🔬 Database Query Agent (The Knowledge Broker)
> *“Bridging data silos to build a panoramic view.”*

*   **⚡ Core Capabilities**:
    *   **Cascade Query Strategy**: A unique waterfall retrieval mechanism — prioritizes Materials Project, and if no result is found, automatically downgrades to OQMD -> COD -> AFLOW, ensuring maximum data recall.
    *   **Multi-Source Heterogeneous Integration**: Automatically aligns crystal structure standards from different databases, providing unified, standardized CIF outputs.
*   **🛠️ Tech Under the Hood**:
    *   Built-in **Intelligent Downgrade Algorithm** makes cross-database routing decisions in milliseconds.

### 3. ⚛️ Simulation & Calculation Agent (The AI Physicist)
> *“Accelerating physical world simulation with the power of Machine Learning.”*

*   **⚡ Core Capabilities (Powered by MatterSim & CrystaLLM)**:
    *   **Generative Materials Design**: Implements "Text-to-Structure" generation from chemical formulas to crystal structures (CIF) based on the **CrystaLLM** model.
    *   **ML Interaction Potential Acceleration**: Integrates **MatterSim** machine learning force fields, boosting structure relaxation and energy calculation speeds by orders of magnitude while maintaining DFT-level accuracy.
    *   **GNoME Stability Assessment**: Directly mounts the GNoME (Graph Networks for Materials Exploration) database, evaluating thermodynamic stability in real-time via **Convex Hull** analysis.
    *   **Phonon Dynamics**: Automated calculation of Phonon Dispersion and Density of States (DOS).
    *   **Thermal Transport Prediction**: Integrates the **AI4Kappa** engine for rapid lattice thermal conductivity prediction.
*   **🛠️ Tech Under the Hood**:
    *   **Generative AI + Physics**: Not just database lookups, but true *ab-initio* level (ML-accelerated) real-time calculations.

### 4. 🧪 Experiment Plan Agent (The Strategist)
> *“The bridge from virtual calculation to physical experimentation.”*

*   **⚡ Core Capabilities**:
    *   **Full-Link Orchestration**: Explores literature frontiers and physical limits, automatically calling the above three agents to gather chains of evidence.
    *   **Dynamic Experimental Design**: Generates structured experimental plans including synthesis paths, characterization methods, and risk assessments.
*   **🛠️ Tech Under the Hood**:
    *   Adopts the **ReAct (Reasoning + Acting)** paradigm, dynamically decomposing complex research goals and autonomously planning verification paths.

## ⚡ Hyper-Speed Workflows

### Scenario I: Zero-to-One Discovery
1.  **Concept**: Tell the **Experiment Plan Agent**: "I want to find a flexible polymer filler with high thermal conductivity."
2.  **Search**: The agent automatically calls the **Literature Agent** to analyze the latest research hotspots (e.g., Boron Nitride, Graphene variants).
3.  **Check**: Calls the **Database Agent** to retrieve band gaps and mechanical properties of existing materials.
4.  **Simulate**: Calls the **Simulation Agent** to generate potential modified structures and calculate thermal conductivity.
5.  **Plan**: Outputs a complete experimental plan containing synthesis steps and testing standards.

### Scenario II: Rapid Verification & Mechanism Analysis
*   **Input**: Directly upload a CIF file to the **Simulation Agent**.
*   **Action**: Enter "Calculate thermal conductivity and analyze stability."
*   **Output**:
    *   ✅ GNoME Stability Score (Stable/Metastable/Unstable)
    *   ✅ Phonon Spectrum (Judging dynamic stability)
    *   ✅ AI4Kappa Thermal Conductivity Prediction
