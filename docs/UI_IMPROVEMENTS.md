# UI 界面改进

## 概述

本文档记录了对前端界面的两个重要改进：
1. **工具调用结果默认展开显示**
2. **图片尺寸优化（限制为对话框宽度的 60%）**

---

## 1. 工具调用结果默认展开

### 问题描述

之前的工具调用记录默认是折叠状态，用户需要手动点击才能查看工具的输出结果。这导致：
- 用户可能忽略重要的工具执行结果
- 需要额外的点击操作才能查看完整信息
- 不利于快速了解 Agent 的工作过程

### 解决方案

修改 `ui/src/components/MessageList.tsx` 中的 `ToolCallsDisplay` 组件：

**修改前**：
```typescript
const ToolCallsDisplay: React.FC<{ toolCalls: any[] }> = ({ toolCalls }) => {
  const [expandedCalls, setExpandedCalls] = useState<Set<number>>(new Set())
  // 默认所有工具调用都是折叠的
```

**修改后**：
```typescript
const ToolCallsDisplay: React.FC<{ toolCalls: any[] }> = ({ toolCalls }) => {
  // 默认展开所有工具调用
  const [expandedCalls, setExpandedCalls] = useState<Set<number>>(
    new Set(toolCalls.map((_, index) => index))
  )
```

### 效果

- ✅ 工具调用记录默认展开，显示输入参数和输出结果
- ✅ 用户可以一眼看到 Agent 调用了哪些工具以及返回了什么结果
- ✅ 仍然支持折叠功能，用户可以点击收起不需要的信息

### 显示内容

每个工具调用卡片包含：
- 🔧 **工具名称**：如 `search_papers`、`save_papers_to_csv` 等
- 📥 **输入参数**：JSON 格式显示传入的参数
- 📤 **输出结果**：JSON 或文本格式显示工具返回的结果
- ⏱️ **执行时间**：显示工具调用的时间戳

## 2. 图片尺寸优化

### 问题描述

对话框中显示的图片（特别是声子谱图）太大，导致：
- 图片占据过多屏幕空间
- 需要滚动才能看到完整对话
- 影响整体阅读体验

### 解决方案

修改 `ui/src/components/MessageList.tsx` 中图片的样式：

**修改前**：
```typescript
<img
  className="w-full h-auto rounded border"
  style={{ maxWidth: '400px', maxHeight: '300px', objectFit: 'contain' }}
/>
```

**修改后**：
```typescript
<img
  className="h-auto rounded border"
  style={{ 
    width: '60%',           // 图片宽度为对话框的 60%
    maxWidth: '100%',       // 不超过容器宽度
    objectFit: 'contain'    // 保持宽高比
  }}
/>
```

### 效果

- ✅ 图片宽度限制为对话框宽度的 60%
- ✅ 保持图片的宽高比，不会变形
- ✅ 在小屏幕上自动适应（不超过容器宽度）
- ✅ 提升对话界面的可读性

### 适用范围

此改进适用于所有在对话消息中显示的图片，包括：
- 声子谱图（phonon dispersion、DOS 等）
- 晶体结构图
- 其他计算结果图
