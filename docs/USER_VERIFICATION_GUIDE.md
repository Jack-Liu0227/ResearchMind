## 🚨 常见问题

### Q1: 我看到了"清除 loading 状态"日志，但进度条仍然转圈

**可能原因**：
- `ProgressTracker` 组件有独立的 loading 状态
- `setIsLoading(false)` 没有生效

**解决方案**：
- 检查 `ProgressTracker` 组件的 `isComplete` 计算逻辑
- 确认 `data.status` 是否正确传递

### Q2: 没有看到"清除 loading 状态"日志

**可能原因**：
- 前端代码没有更新（浏览器缓存）
- WebSocket 消息中的 `status` 字段不是 `"success"`

**解决方案**：
- 强制刷新浏览器（Ctrl+Shift+R）
- 检查 WebSocket 消息中的 `status` 字段值

### Q3: 控制台显示 `status=undefined`

**可能原因**：
- 后端没有发送 `status` 字段
- 后端代码没有更新

**解决方案**：
- 检查后端日志：`Get-Content logs/paper_search.log -Tail 50`
- 确认后端代码已更新
