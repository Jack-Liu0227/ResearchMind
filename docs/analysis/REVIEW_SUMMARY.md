## ⚠️ 潜在问题和风险

### 🔴 高风险

1. **内存泄漏** - 大量论文处理时可能内存泄漏
   - **缓解**：添加内存监控，使用 `tracemalloc`

2. **API 限流** - 并发请求可能触发限流
   - **缓解**：添加指数退避重试，检测 429 错误

3. **WebSocket 断开** - 长时间任务中连接可能断开
   - **缓解**：添加连接检测，支持重连恢复

### 🟡 中风险

4. **并发竞态条件** - Semaphore 共享状态可能有竞态
   - **缓解**：全面测试，使用原子操作

5. **Prompt 注入** - 用户内容可能包含恶意 Prompt
   - **缓解**：输入清理，系统消息限制

### 🟢 低风险

6. **时区问题** - `datetime.now()` 可能不一致
   - **缓解**：统一使用 UTC 时间
