## 🚀 第一步：选择您的智能助手

在左侧的功能选择区，请根据您的任务选择最合适的助手：

1.  📚 **文献研究助手 (Literature Research)**
    - **用途：** 当您需要快速了解某个研究领域、查找关键论文或生成结构化的文献综述时，选它。
    - **核心能力：** AI帮你读论文，写综述，理清研究脉络。

2.  📊 **数据库查询助手 (Database Query)**
    - **用途：** 当您需要查询某种材料的晶体结构、能带、态密度等物理性质时，选它。
    - **核心能力：** AI帮你从海量专业数据库里精准查找材料数据。

3.  🔬 **仿真计算助手 (Simulation & Calculation)**
    - **用途：** 当您拥有材料的结构文件（如 CIF），需要从头计算其物理性质（如热导率、声子谱）时，选它。
    - **核心能力：** AI帮你运行复杂的仿真计算，并对结果进行可视化分析。

## 🎮 核心功能深度解析

### 📚 如何玩转【文献研究助手】？

**目标：** 让AI生成一份关于“钙钛矿太阳能电池稳定性”的深度研究报告。

1.  **选择助手：** 在左侧点击 📚 **文献研究助手**。
2.  **下达精准指令：** 在对话框中，输入您的研究主题。**指令越具体，结果越好**。
    > "生成一份关于提升钙钛矿太阳能电池稳定性的最新策略的详细报告，重点关注材料改性和封装技术。"
3.  **分析与使用结果：**
    - **阅读报告：** 右侧会生成一份结构化报告，通常包含**引言、关键论文摘要、技术分类讨论、结论**等部分。您可以直接复制报告内容。
    - **下载数据：** 报告下方会提供一个 **CSV文件下载链接 (⬇️)**。该文件包含所有参考文献的**标题、作者、期刊、年份、摘要和URL**，是您管理文献的利器。
    - **追问与深化：** 您可以基于报告结果继续提问，例如：“请详细介绍报告中提到的ALD封装技术。”

`[GIF动图：展示从选择文献助手到输入具体指令，再到右侧生成报告、下载CSV，并进行追问的全过程]`

### 📊 如何玩转【数据库查询助手】？

**目标：** 查找 “金刚石 (Diamond)” 的晶体结构和带隙。

1.  **选择助手：** 在左侧点击 📊 **数据库查询助手**。
2.  **下达指令：** 在对话框中，清晰地说明您要查询的材料和性质。
    > "查询金刚石的晶体结构和带隙"
3.  **分析与使用结果：**
    - **查看数据：** 右侧会展示从权威数据库（如 Materials Project）中找到的**详细材料信息**，包括晶格常数、空间群、带隙值等。数据旁边通常有**复制按钮 (📋)**，方便您使用。
    - **与3D模型互动：** 您会看到一个**可交互的3D晶体结构模型**。
        - **旋转：** 按住鼠标左键拖动。
        - **缩放：** 滚动鼠标滚轮。
        - **平移：** 按住鼠标右键拖动。
    - **下载结构文件：** 通常模型下方会提供 **CIF/POSCAR 等格式的下载链接 (⬇️)**，方便您将结构导入到其他软件中。

`[GIF动图：展示查询金刚石，然后在右侧与3D模型互动（旋转/缩放），并点击复制带隙数据、下载CIF文件的过程]`

### 🔬 如何玩转【仿真计算助手】？

**目标：** 计算一个 `MoS2.cif` 文件的声子谱。

1.  **选择助手：** 在左侧点击 🔬 **仿真计算助手**。
2.  **上传文件：** 点击对话框下方的 **“上传文件”按钮 (📎)**，选择您的 `MoS2.cif` 文件。
    `[图片：截图高亮显示“上传文件”按钮]`
3.  **下达指令：** 文件上传成功后，在对话框中输入您的计算要求。
    > "计算这个二硫化钼结构的声子谱，并分析其动力学稳定性"
4.  **分析与使用结果：**
    - **查看数值结果：** 计算完成后，右侧会首先展示关键的**计算参数和结论**，例如“未发现虚频，结构动力学稳定”。
    - **分析图表：**
        - 您会得到一张专业的**声子谱图**。将鼠标悬停在图上可以查看具体数据点的数值。
        - 图表右上角通常有**下载按钮 (⬇️)**，可将图片保存为 PNG 或 SVG 格式。
    - **与3D模型互动：** 您上传的晶体结构也会以3D模型展示，方便您对照检查。

`[GIF动图：展示上传MoS2.cif文件，输入计算指令，最后在右侧查看声子谱图、悬停查看数据并下载图表的过程]`

## 💰 理解收费标准

**ResearchMind 的计费模式是“按用付费”，力求透明和公平。**

- **什么时候不花钱？**
  - 与AI进行普通聊天、提问、查询您的对话历史。
  - 使用数据库查询助手进行常规的材料性质查询。

- **什么时候会花钱？**
  - 当AI需要调用**昂贵的外部工具**来完成您的指令时，才会产生费用。主要包括：
    1.  **文献研究助手：** 进行深度的、多源的文献检索和报告生成。
    2.  **仿真计算助手：** 在云端服务器上执行耗费计算资源的物理仿真（如热导率、声子谱计算）。

- **如何计费？**
  - 在您发出可能产生费用的指令后，AI在执行前**通常会向您确认**。
  - 每一项付费工具都有明确的标价，您可以在应用的“计费说明”页面查看详情。

**核心理念：** 简单的查询和交互是免费的，只有当您使用重量级功能时才需要付费。

## 💡 常见问题与高级技巧 (FAQ & Pro Tips)

- **Q: 我的计算失败了/查询没有结果怎么办？**
  - **A:** 首先检查您的输入。对于计算，请确保上传的**CIF文件结构有效**。对于查询，请尝试**更换关键词**（例如用化学式 "SiO2" 代替 "二氧化硅"）。如果问题仍然存在，可以尝试简化指令再试一次。

- **Q: 我可以保存我的工作吗？**
  - **A:** 当然！您的所有**对话历史和生成的结果都会自动保存在您的账户中**。您随时可以回顾、复制或下载之前的成果。

- **Pro Tip 1: 指令的艺术**
  - **要具体，不要模糊。** 与其说“找一种新材料”，不如说“寻找一种具有高介电常数和宽带隙的透明导体材料”。

- **Pro Tip 2: 善用追问**
  - AI记得上下文。您可以基于它的回答进行**多轮追问**，逐步深入，就像和一位真正的专家讨论一样。

- **Pro Tip 3: 结果再利用**
  - 您可以将在【数据库查询助手】中下载的CIF文件，直接上传到【仿真计算助手】中进行计算，实现工作流的无缝衔接！
