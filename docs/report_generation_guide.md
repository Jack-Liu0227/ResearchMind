# 报告生成指南

## 概述

系统使用 **综合报告模式** 生成深度研究调研报告，包含：
- 研究概述、技术路线、趋势分析、研究空白
- 每篇论文的详细分析（6部分结构）
- 参考文献列表

## 报告结构

```
# {主题} - 研究调研报告

## 研究概述
- 研究领域的重要性和背景
- 当前研究的主要挑战
- 本次调研的文献范围

## 技术路线分析
- 主流技术方法对比
- 各方法的优缺点
- 技术演进趋势

## 研究热点与趋势
- 当前研究热点
- 未来发展方向
- 潜在突破点

## 研究空白与机会
- 现有研究的局限性
- 尚未解决的问题
- 可能的研究方向

## 总结与建议
- 主要结论
- 对研究者的建议
- 未来展望

## 详细文献分析

### 论文1: {标题}

#### 1. 研究背景与动机
- 研究解决什么问题？
- 为什么这个问题重要？

#### 2. 研究目标
- 具体的研究目标是什么？

#### 3. 方法论
- 使用了什么方法？
- 方法有何创新之处？

#### 4. 主要发现与结果
- 关键结果是什么？
- 有哪些重要发现？

#### 5. 创新点与贡献
- 这项工作的创新之处？
- 对领域的贡献？

#### 6. 局限性
- 存在哪些局限性？
- 有哪些未解决的问题？

### 论文2: ...

## 参考文献
```

## 容错机制

系统有完整的三层容错机制，确保在各种情况下都能生成报告：

### 第一层：全文获取失败
```
获取全文
├─ 成功 → 使用全文
├─ 超时 → 使用摘要作为 full_text
└─ 失败 → 使用摘要作为 full_text
```

### 第二层：内容选择
```
选择分析内容
├─ full_text 存在且 >100字符 → 使用全文（标注"全文"）
├─ abstract 存在且 >50字符 → 使用摘要（标注"摘要"）
└─ 都不存在 → 使用标题（标注"仅标题"）
```

### 第三层：LLM分析失败
```
LLM分析
├─ 成功 → 返回完整的6部分分析
├─ 超时 → 返回fallback（6部分结构 + 内容预览）
└─ 失败 → 返回fallback（6部分结构 + 错误信息）
```

## 使用示例

```python
from mcp_servers.paper_search.modules.report_generator.reporting import generate_research_report_with_data_collection

# 生成报告
result = await generate_research_report_with_data_collection(
    papers_info=papers_list,  # 论文信息列表
    topic="深度学习在医学影像中的应用",  # 研究主题
    papers_analysis=None  # 可选的预分析结果
)

# 检查结果
if result['status'] == 'success':
    report_content = result['report']
    print(f"报告生成成功，共 {result['papers_count']} 篇文献")
else:
    print(f"报告生成失败：{result['error']}")
```

## 性能参数

| 参数 | 值 | 说明 |
|------|---|------|
| 全文获取超时 | 30秒 | 单篇论文全文获取超时时间 |
| 分析超时 | 60秒 | 单篇论文LLM分析超时时间 |
| 并发任务数 | 10个 | 同时处理的论文数量 |
| 内容截断 | 3000字符 | 送入LLM的内容长度限制 |
| 分析Token | 1500 | 单篇论文分析的最大token数 |
| 综合Token | 2000 | 综合总结的最大token数 |

## 故障排查

### 问题1：报告生成失败

**可能原因**：
- LLM API配置错误
- 网络连接问题
- API配额用尽

**解决方案**：
1. 运行诊断工具：`python scripts/diagnose_llm_config.py`
2. 检查环境变量：`OPENAI_API_KEY`, `OPENAI_BASE_URL`, `MODEL_USE`
3. 查看日志中的详细错误信息

### 问题2：分析质量不佳

**可能原因**：
- 使用摘要而非全文
- 内容太短或质量差

**解决方案**：
1. 检查日志中的"分析依据"标注（全文/摘要/仅标题）
2. 如果是"摘要"或"仅标题"，说明全文获取失败
3. 检查论文来源的可访问性
