# ResearchMind V2.0 深度文献研究系统增强版

## 🎉 新功能概览

ResearchMind 深度文献研究系统已经升级为完整的 **6步引导式工作流程**，并增加了 **自动报告保存** 功能！

## 🚀 核心改进

### 1. 完整的6步工作流程
- 🎯 **步骤 1**: 研究分类分析 - 智能分析用户的研究需求和范围
- 📝 **步骤 2**: 制定研究计划 - 创建详细的搜索和分析策略
- ✅ **步骤 3**: 用户确认执行 - 征得用户同意后开始执行
- 🔍 **步骤 4**: 文献搜索执行 - 使用多种策略收集相关论文
- 📊 **步骤 5**: 深度分析报告 - 综合分析找到的文献并提取见解
- 📄 **步骤 6**: 生成并保存最终报告 - 创建结构化报告并自动保存

### 2. 智能工作流程控制
- **状态跟踪**: 系统自动跟踪当前工作流程阶段
- **断点续传**: 支持在任意阶段暂停和恢复
- **用户控制**: 每个关键步骤都需要用户确认
- **错误恢复**: 智能处理异常并提供重启选项

### 3. 自动报告保存 📁
研究完成后，系统会自动生成并保存两种格式的报告：

#### 📄 Markdown 格式报告
- **位置**: `reports/research_report_YYYYMMDD_HHMMSS.md`
- **内容**: 完整的研究报告，包含所有6个步骤的详细信息
- **格式**: 结构化的Markdown文档，易于阅读和分享

#### 📊 JSON 格式报告
- **位置**: `reports/research_report_YYYYMMDD_HHMMSS.json`
- **内容**: 结构化数据，便于程序处理和分析
- **用途**: 支持后续数据分析、报告合并等操作

## 📋 报告内容结构

### Markdown 报告包含：
```markdown
# ResearchMind 深度文献研究报告

## 🎯 研究分类结果
- 研究类型分析
- 范围确定
- 方法建议

## 📝 研究计划
- 搜索策略
- 关键词组合
- 数据库选择
- 分析重点

## 🔍 文献搜索结果
- 找到的论文列表
- 主要发现总结
- 重要文献推荐

## 📊 深度分析报告
- 关键技术发现
- 研究趋势分析
- 知识空白识别
- 未来方向建议

## 📄 结论与建议
- 工作流程总结
- 下一步建议
- 系统信息
```

### JSON 报告结构：
```json
{
  "classification": "分类分析内容",
  "planning": "研究计划内容", 
  "research_results": "搜索结果内容",
  "analysis": "深度分析内容",
  "timestamp": "2025-10-02T22:08:08.031928",
  "workflow_completed": true
}
```

## 🔧 使用方法

### 1. 启动研究流程
只需向 ResearchMind 提出研究请求，例如：
```
"我想研究高熵合金在高温下的力学性能演化"
```

### 2. 系统自动引导
系统会依次执行6个步骤，在关键节点请求您的确认：

1. **分类阶段** - 系统自动分析您的研究需求
2. **计划阶段** - 自动生成详细的研究策略
3. **确认阶段** - 询问："准备开始执行研究吗？"
4. **搜索阶段** - 根据计划执行文献搜索
5. **分析阶段** - 深度分析搜索结果
6. **报告阶段** - 生成并保存最终报告

### 3. 获取报告
研究完成后，您会收到：
- 📍 报告保存位置的确切路径
- 📄 包含完整分析的 Markdown 文件
- 📊 便于后续处理的 JSON 数据文件
